# Claude Code Project Instructions

Read `AGENTS.md` first. It is the canonical repository policy.

Then read the project documents listed in `README.md` before implementing a major milestone.

Do not begin by generating the whole application. Start by auditing the repository and producing a concise risk/ambiguity report. Then execute milestones from `IMPLEMENTATION_PLAN.md` in order.

At the end of every milestone:

- run the required validation commands;
- inspect the diff;
- update tests and docs;
- report exactly what was verified.

Never invent performance measurements or claim correctness that has not been tested.
